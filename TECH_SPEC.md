# Техническое задание (ТЗ)
**Название проекта:** S3 Desktop Explorer (MinIO Studio)  
**Платформа:** Windows (с архитектурной готовностью под macOS и Linux)  
**Технологический стек:** 
* **Оболочка:** Electron
* **Интерфейс (Frontend):** React / Vue 3 + Tailwind CSS + Radix UI / Shadcn
* **Управление состоянием:** Zustand / Pinia
* **Основной процесс (Node.js):** `@aws-sdk/client-s3`, `chokidar` (файловый вотчер), `better-sqlite3` (локальный кэш и сессии), `keytar` (безопасное хранение ключей в Windows Credential Manager).

---

## 1. Концепция и архитектура (Open-Core)

Приложение реализуется по модели Open-Core с разделением на две редакции:
1. **Community Edition (Бесплатная / Open Source):** быстрый, интуитивный файловый менеджер для MinIO / S3 с базовым встроенным просмотром и вызовом внешних приложений в режиме «только чтение».
2. **Pro Edition (Платная коммерческая версия):** двусторонняя прозрачная синхронизация редактируемых локально файлов (Word, Excel и др.), полноценная GUI-замена консольного `mc.exe`, расширенные функции безопасности и автоматизации.

---

## 2. Функциональные требования

### 2.1. Бесплатная версия (Community Edition)

#### А. Управление подключениями
* Хранение до 3 активных профилей подключения.
* Параметры:
  * Название профиля
  * Endpoint URL (например, `http://localhost:9000` или `https://s3.example.com`)
  * Region (по умолчанию `us-east-1` для MinIO)
  * Access Key и Secret Key
  * Чекбокс использования SSL/TLS
  * Чекбокс `s3ForcePathStyle` (критично для совместимости с MinIO)
* Безопасное хранение чувствительных данных через OS Keyring (`keytar`).
* Кнопка проверки соединения (Ping/Test connection).

#### Б. Навигация и файловый менеджер
* Двухпанельная компоновка:
  * Левая панель: дерево бакетов с быстрым переходом.
  * Центральная панель: список объектов текущего бакета/папки.
* Режимы отображения: Таблица (детальный список) и Сетка (плитка с иконками).
* Поддержка виртуальных директорий (разделитель `/`).
* Сортировка по колонкам: Имя, Размер, Дата изменения, Тип/Расширение.
* Поиск/фильтрация по префиксу внутри открытой директории.
* Хлебные крошки (breadcrumbs) в верхней части с поддержкой перехода на любой уровень.

#### В. Базовые файловые операции
* Загрузка файлов и папок через Drag-and-Drop и стандартный диалог Windows.
* Скачивание выбранных файлов/папок с сохранением структуры.
* Создание новых папок (пустых маркеров каталогов).
* Создание и удаление бакетов.
* Множественный выбор файлов (`Shift + Click`, `Ctrl + Click`, рамка выделения).
* Менеджер очереди задач (Queue Manager):
  * Прогресс-бар для активных операций.
  * Отображение текущей скорости передачи и оставшегося времени.
  * Пауза, возобновление и отмена операций.

#### Г. Встроенный просмотрщик (Preview Panel)
* Быстрый предпросмотр по клавише `Space` (Quick Look) или в боковой шторке:
  * **Изображения:** PNG, JPG, GIF, WebP, SVG.
  * **Текст и логи:** TXT, LOG, JSON, XML, YAML (с подсветкой синтаксиса).
  * **Документы:** PDF (встроенный легковесный просмотр на базе `pdf.js`).
  * **Медиа:** MP3, WAV, MP4, WebM (стандартные плееры HTML5).

#### Д. Открытие в сторонних программах (односторонняя передача)
* Пункт контекстного меню «Открыть во внешней программе»:
  1. Объект скачивается во временную директорию ОС (`%TEMP%/s3-explorer/...`).
  2. Запускается ассоциированное системное приложение через `shell.openPath`.
  3. В бесплатной версии изменения файла в сторонней программе не отслеживаются.

### 2.2. Платная версия (Pro Edition)

Включает весь функционал бесплатной версии, а также:

#### А. Двустороннее редактирование "Edit-in-Place" (Киллер-фича)
* **Алгоритм работы:**
  1. Пользователь выбирает «Редактировать в приложении» (например, файл `.docx`).
  2. Файл скачивается в изолированную рабочую директорию приложения.
  3. Запускается Microsoft Word (или соответствующая ассоциированная программа).
  4. Фоновый сервис на базе `chokidar` начинает следить за изменениями файла на диске.
  5. При каждом сохранении (`Ctrl + S` в Word) фиксируется изменение.
  6. Приложение предлагает автоматически или по клику отправить обновленный файл обратно в MinIO через `PutObject`.
  7. Поддержка версионирования: создание новой версии объекта без перезаписи предыдущей.
  8. Опциональная установка soft-lock метки в метаданные объекта для предотвращения конфликтов редактирования.

#### Б. Полная GUI-замена возможностей `mc.exe`
* **Политики доступа и IAM:**
  * Графический конструктор и встроенный JSON-редактор IAM-политик.
  * Управление пользователями MinIO (создание, удаление, смена пароля, привязка политик).
  * Управление сервисными аккаунтами (Service Accounts / Access Keys).
* **Конфигурация бакетов (Bucket Lifecycle & Management):**
  * Lifecycle Rules: настройка автоматического удаления или архивации объектов по истечении дней.
  * Object Versioning: включение, приостановка, просмотр истории версий каждого объекта и откат к старой версии.
  * Управление квотами бакетов (Bucket Quotas).
  * Настройка репликации между кластерами (Server-Side Replication).
  * Настройка шифрования на стороне сервера (SSE-S3, SSE-KMS).

#### В. Продвинутая работа с данными и автоматизация
* **Мультиаккаунты и мультиокна:**
  * Неограниченное число сохраненных профилей.
  * Двухпанельный режим (Total Commander style): Бакет A слева, Бакет B справа для прямого копирования между бакетами/кластерами.
  * Поддержка вкладок (Tabs).
* **Синхронизация директорий (Folder Sync / Mirror):**
  * Графический аналог `mc mirror`: односторонняя или двусторонняя синхронизация локальной папки с бакетом.
  * Фильтрация файлов по маске (exclude/include glob patterns).
  * Фоновое расписание синхронизации.
* **Генерация Presigned URLs:**
  * Создание временных ссылок на скачивание или загрузку с кастомным временем жизни (от 1 минуты до 7 дней).
* **Расширенный встроенный редактор:**
  * Встроенный **Monaco Editor** (ядро VS Code) для быстрого редактирования конфигов, скриптов и JSON прямо в бакете.
  * Интерактивный просмотр и базовое редактирование электронных таблиц `.xlsx`, `.csv`.

#### Г. Безопасность и командная работа
* Блокировка интерфейса мастер-паролем / PIN-кодом при бездействии.
* Зашифрованный экспорт/импорт профилей подключений для безопасного обмена конфигурациями внутри команды.

## 3. Нефункциональные требования

1. **Производительность:**
   * Время холодного запуска — не более 2.5 секунд.
   * Виртуализация списков (Virtual Scrolling): отрисовка директорий с 100 000+ объектов без просадки FPS интерфейса.
   * Пагинация запросов через `ContinuationToken` из AWS SDK.
2. **Отказоустойчивость передачи данных:**
   * Использование S3 Multipart Upload для файлов более 10 МБ.
   * Параллельная передача чанков (3–5 потоков).
   * Возможность докачки при кратковременном обрыве связи.
3. **Кроссплатформенность кодовой базы:**
   * Изоляция системных вызовов через кроссплатформенные абстракции Node.js (`path.posix`/`path.win32`, `os.tmpdir()`).
4. **Обновления:**
   * Встроенный механизм автообновления через `electron-updater` с GitHub Releases.
