## 🎯 Брендинг и продуктовый бриф

- **Официальный бренд:** **Syncra** (Syncra S3)
- **Слоган / Дескриптор:** *Direct Desktop Client for S3 & MinIO*
- **Логотип & Айдентика:** Текучая светящаяся неоновая лента Мебиуса, соединяющая литеру **«S»** и силуэт облака в палитре Mint → Cyan → Cobalt на обсидиановом фоне.
- **Главные преимущества продукта:**
  1. **Edit-in-Place:** Прямое открытие и редактирование файлов Word, Excel, Photoshop прямо из облака с автосохранением в бакет по `Ctrl + S`.
  2. **Встроенный редактор кода Monaco:** Полноценная среда для правки конфигов JSON, YAML, SQL прямо в хранилище.
  3. **Визуальный центр управления MinIO:** Графический пульт мониторинга серверов, управления пользователями и политиками безопасности вместо терминала.
  4. **Нативная интеграция с Windows:** Копирование файлов в системный буфер обмена (`Ctrl + C` в Syncra → `Ctrl + V` в Проводник).
- **Модель монетизации:**
  - *Syncra Trial:* 14 дней 100% профессионального доступа без привязки карты.
  - *Syncra Community:* Бесплатно навсегда (до 3 серверов, базовые файловые операции).
  - *Syncra Pro Lifetime:* \$29 разово (бессрочная лицензия + 1 год обновлений).
